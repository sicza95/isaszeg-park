# Offline national flags

Vendored from [lipis/flag-icons](https://github.com/lipis/flag-icons), version 7.5.0,
using the published npm archive `https://registry.npmjs.org/flag-icons/-/flag-icons-7.5.0.tgz`.
The original 4:3 SVGs and MIT copyright notice are included here.

These files ship with the desktop app and are served locally in the browser demo.
There are no remote image URLs, web fonts, CDN stylesheets or runtime downloads.
`src/shared/countries.mjs` lists the two-letter country assets for country pickers.
